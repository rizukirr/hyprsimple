# hyprsimple

Minimalist and aesthetically pleasing Hyprland dotfiles for Arch Linux. Just the essential utilities for everyday use, with a clean and beautiful look and feel. Nothing fancy.

**Documentation: [rizukirr.github.io/hyprsimple-web](https://rizukirr.github.io/hyprsimple-web/)**

The website has everything else: [installing](https://rizukirr.github.io/hyprsimple-web/docs/install), [updating](https://rizukirr.github.io/hyprsimple-web/docs/update), [every keybinding](https://rizukirr.github.io/hyprsimple-web/keys), [the scripts](https://rizukirr.github.io/hyprsimple-web/docs/scripts), [making a theme](https://rizukirr.github.io/hyprsimple-web/docs/theming), [plugins](https://rizukirr.github.io/hyprsimple-web/docs/plugins) and [the FAQ](https://rizukirr.github.io/hyprsimple-web/docs/faq). You can also try every theme there.

## Install

```bash
git clone https://github.com/rizukirr/hyprsimple.git
cd hyprsimple
./install.sh
```

The install asks for your sudo password once, at the start, and then runs to the end without stopping. `./install.sh --interactive` puts every confirmation back. Read [the install guide](https://rizukirr.github.io/hyprsimple-web/docs/install) first if you are coming from another desktop.

To update an install, run `hyprsimple-update`. It never overwrites your `~/.config`.

## Problems

Run `hyprsimple-debug` and attach the link it gives you to an [issue](https://github.com/rizukirr/hyprsimple/issues). Many problems already have an answer in [the FAQ](https://rizukirr.github.io/hyprsimple-web/docs/faq).
